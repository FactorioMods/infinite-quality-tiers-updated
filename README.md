# Infinite Quality Tiers: Updated

Adds an endgame infinite technology that unlocks further quality tiers beyond the normal progression.

This fork retains the original repeatable quality progression and its configuration options for Factorio 2.1.24. Quality support is required.

Requires Factorio 2.1.24 or later. Disable `infinite-quality-tiers` before enabling this fork. Required content and optional integrations are listed in the mod dependencies.
